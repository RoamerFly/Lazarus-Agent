## 作品名称

遗留软件复活智能体

## 作品简介

一线设备升级后，早期离线巡检或文件读取工具可能因旧版 Android 依赖失效，源码和维护团队也可能已不可获得。遗留软件复活智能体让维护人员导入 APK、选择目标 Android，并通过对话描述要恢复或新增的行为。Agent 读取清单、资源、反汇编代码和设备证据，自主选择受限工具，生成并签名候选。工作台分别记录构建、安装和功能结果，按固定步骤独立复测并核对安装文件哈希。模拟巡检案例恢复旧包安装并保留上次打开的路线。Android 16 x86_64 固定评测共 42 轮，正例 18/18，留出样本 3/3，反例 6/6 明确拒绝。Windows 版支持按需准备环境、关闭模型运行本地规则，以及复测已有候选。

## 开源及第三方组件声明

项目实现了需求编排、受限工具调用、候选留档和独立行为验收。软件开发和材料整理使用 AI 辅助，在线 Agent 演示与评测使用 DeepSeek Flash，模型服务由使用者自行配置。工程复用 Python、FastAPI、Uvicorn、pywebview、Apktool 和 Android SDK 工具等第三方组件，依赖及版本以对应源码和组件发布方声明为准。Windows 界面使用 Microsoft Edge WebView2 Runtime，Android SDK、模拟器镜像和 Java 等运行资源按需获取。随评审包提供的 APK 为团队自制合成样本及其候选，可供本届赛事复核。公开源码地址为 https://github.com/RoamerFly/Lazarus-Agent/tree/v0.6.16 。
