# v0.6.25 干净 Windows 复核

在 VMware 新建空白虚拟磁盘，从安装介质部署 Windows Server 2022 Standard 桌面体验版（20348.1006）。虚拟机没有虚拟网卡及共享目录。首次复核前，Windows PowerShell 5.1 找不到 Java、ADB、Android 模拟器和 Python。应用专用环境变量与用户 Android SDK 均不存在。经只读介质传入固定的 v0.6.25 EXE、离线样本 ZIP、NSIS 3.11 及安装复核脚本。

| 检查 | 结果 |
| --- | --- |
| 包内容 | 解压并核对 16 个登记文件的 SHA-256 |
| EXE 复测入口 | P03 的四步及 P05 的八步均通过 `-CheckOnly` 输入校验 |
| 隔离安装、自检和卸载 | 均返回 0，安装后 EXE 哈希与便携版一致，卸载后测试注册项移除且导出文件保留 |
| 缺少 WebView2 | 首次启动显示 WebView2 安装提示，未启动渲染进程 |
| 补装后首次打开 | 用 Microsoft 签名的 x64 离线安装器补装 WebView2 157.0.4341.42，独立桌面窗口正常显示，本地工作台返回 HTTP 200 |

本轮真实模型调用为 0。同版 Android 16 x86_64 行为验收来自已准备好模拟器的 Windows 环境。本虚拟机验证干净系统的 Windows 安装、桌面启动和样本入口。虚拟机内首次下载 Android 环境及运行设备步骤另行验证。

从交付目录取得同版 EXE 与样本 ZIP。解压后按包内《从这里开始》运行文件校验和两份样本的 `-CheckOnly`。使用源码 `c5f9799c748d700250a5b27d666bae00609acb50` 的 `tools/test_local_windows_install.ps1` 可复跑安装、自检、卸载。桌面缺少运行时可按微软说明安装。截图和合并回执存放在 `交付/v0.6.25-本地候选`。[微软 WebView2 分发说明](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)
