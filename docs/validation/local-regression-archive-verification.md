# 本地回归复测包的一致性复核

本地复测 ZIP 现在交叉核对构建回执、评测源码版本、审计汇总、差异审查、可分发 APK 与反例报告。新打包文件额外附带冻结协议和实际执行计划，校验器同时核对计划字段和协议文件哈希。

使用 v0.6.22 的原始回归数据，从同版 EXE 和构建回执重建 ZIP。原历史 ZIP 与重建 ZIP 均通过归档校验，包含 42 轮终态、15 份审查批准的候选和一个矛盾断言反例。

| 重新计算外层哈希后的变体 | 新版结果 |
| --- | --- |
| 用曾被排除的文件交接 APK、原包及验收报告替换已批准样本 | 拒绝，样本与对应轮次的审计哈希不一致 |
| 修改反例报告，保留原断言和失败状态 | 拒绝，反例报告的原始哈希不一致 |
| 改写计划中的冻结提交 | 拒绝，计划与审计汇总不一致 |
| 改写构建回执中的 EXE 哈希 | 拒绝，回执与审计汇总不一致 |

四种变体曾被旧版校验器放行。正式 v0.6.18 评审包及 v0.6.19 签名附录仍通过原有核验。本轮验证留存文件的一致性。[前后对照与归档哈希](local-regression-verifier-proof.json)
