# v0.6.28 无模型归档修复

在 Windows 主机使用 v0.6.28 便携 EXE，关闭模型后导入自制归档阅读器 P02，选择 Android 16。原包安装和启动后，点击打开记录触发缺类崩溃。工作台在专用模拟器观察到 `org.apache.http.ProtocolVersion` 缺失，由本地规则生成兼容候选。实际模型调用为零。

通过 APK 清单回读，候选添加了 `org.apache.http.legacy` 声明，权限和组件声明无变化。除清单和重新签名数据外，包内 `classes.dex` 与 `resources.arsc` 均逐字节一致。

从已完成任务导出候选，关闭该任务的专用模拟器，使用同一 EXE 独立复测。Android 16 x86_64 实际安装、启动、打开记录、冷启动后再次打开均通过，六步完成。独立验收安装回读 SHA-256 与工作台导出 SHA-256 一致。

复测包包含原包、候选、独立设备报告和复测脚本。ZIP 校验与样本身份验证通过。解压后以 Windows PowerShell 5.1 校验九个文件，同版 EXE 通过 `-CheckOnly`。
