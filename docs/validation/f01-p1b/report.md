## 证据与适用范围

- 巡检单第三轮的点击触发 `NoSuchMethodError`。Agent 后来定位到接口签名错误，但该轮构建额度已耗尽，没有可交付候选。[专用模拟器诊断](p01-runtime-observation.json)
- 归档阅读器原 APK 没有实际归档文件。部分候选新增合成响应并在运行时读取它，规则对照通过兼容库保留原有输出。固定断言核验 HTTP/1.1 的界面结果。第三轮改用重新实现的读取路径，构建额度耗尽时仍未通过。
- 通过候选逐份核对差异、候选哈希和安装回读哈希。逐轮记录包含构建尝试、时延、设备验收阶段及已返回的计量。
- 保存 443 条有用量记录的模型响应，按冻结单价估算为 0.1551 至 0.3102 美元。其余测试开销与真实账单需分别核对。
