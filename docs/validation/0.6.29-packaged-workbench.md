# v0.6.29 便携工作台与设备预检复核

本地构建来自 `0e95b5f`，EXE 自检通过。测试通过打包后的 Windows 工作台正常导入和对话接口执行。模型兼容接口指向本机留档工具服务，实际模型请求为零。

| 用例 | 预检 | 预检后操作 | 导出与独立验收 |
| --- | --- | --- | --- |
| 自有巡检单 | Android 16 x86_64 安装、启动及十步通过 | 直接读取同一候选的前台 | 下载接口开放，下载件由同一便携 EXE 重跑十步并通过 |
| OI 记事本 | 安装和启动通过，在许可页止步 | 直接读取候选前台并确认许可页 | 分析结束，功能验收未通过，无可下载候选 |

巡检单下载、工作台验收和便携 EXE 独立设备回读的哈希一致。专项复测包仅分发自有巡检单原包、候选 APK 和复测材料。Windows PowerShell 解包后九个登记文件及同版样本输入通过校验。

另按冻结用例从留档编辑重新构建四个正例和一个反例。四个正例通过 38 步，N03 安装启动通过后拒绝矛盾断言。这个批次是同版离线工程复跑。真实旧记事本的复核标记行为仍待验证。

另一次录制使用同一套巡检单步骤。预检十步通过，随后的独立验收冷启动时仍显示南线，第九步失败，录制未生成成功视频。对录制产生的同一签名 APK 独立复跑后通过十步。保留两次结果，触发原因尚待定位。[录制复跑回执](0.6.29-demo-recheck.json)
