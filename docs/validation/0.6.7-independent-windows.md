## 正式发布包的首次运行环境准备

[Fresh Windows runtime 42019764836](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42019764836) 在另一台新 runner 下载安装正式 v0.6.7 发布包，核对文件哈希后静默安装并启动实际桌面程序。该试验清空 SDK 和 Java 的进程环境配置，限制 PATH，并指定未存在的应用存储根目录。

运行前通过工作台 API 记录的五类组件均缺失，包括 platform-tools、emulator、build-tools、API 36 系统镜像和 Java。调用工作台自身的准备入口后，状态变为 ready。准备约 66.02 秒，运行目录占用 3,483,902,577 字节，约 3.24 GiB。该结果来自 GitHub 托管网络和硬件，不代表普通家庭网络速度。第二次调用返回 ready 且未启动下载。

WHPX 检查返回 installed and usable。此次任务完成运行环境准备，后续的 Android 断网行为复测单独按终态报告核对。

原始日志与证据在本机 `build/f01-review/fresh-windows-067`、`fresh-runtime-067`、`packaged067` 和发布清单目录中。
