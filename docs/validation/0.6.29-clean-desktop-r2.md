# v0.6.29 r2 空盘 Windows 复核

在独立虚拟磁盘上安装 Windows Server 2022 Standard 20348.1006。来宾没有活动网卡、Android SDK、Java、ADB、模拟器、Python 或项目相关环境变量。使用 r2 原始 ZIP 和同版便携 EXE 测试，ZIP 的 SHA-256 为 `ea5978768bef41f447a50f4737a64f954bb6724982422d41002f979cfc1c7546`。

- Windows PowerShell 5.1 核对 91 个登记文件。同版便携 EXE 核对 6 份样本输入，包含演示和矛盾断言反例。样本、验收步骤数量和候选哈希与 r2 一致。
- 使用包内修订脚本生成隔离安装器。安装、自检和默认卸载均返回 0。安装后的 EXE 与便携文件哈希一致。卸载移除隔离注册项，保留测试导出文件。
- 校验 WebView2 安装包发布者签名后，在实际登录会话中运行同一便携 EXE。探针确认 Lazarus Agent 原生窗口、6 个 WebView2 渲染进程和本地 HTTP 200。
