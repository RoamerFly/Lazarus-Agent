# v0.6.14 干净 Windows 从原包执行本地规则

[独立运行 42060092447](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42060092447) 使用正式 v0.6.14 安装器。应用存储与 TEMP 均含中文和空格，首次准备缺失工具和镜像后验证复用，再限制工作台、Java、ADB 和模拟器的 Internet 出站。模型配置为空，保留本机工作台与模拟器之间的通信。
