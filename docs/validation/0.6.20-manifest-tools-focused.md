## 在专用模拟器重放外部调用

从仓库源码运行以下命令。把候选 APK 路径替换为该轮留档的自有测试样本路径。脚本核对包名与哈希，使用专用 Android 16 x86_64 模拟器并在完成后关机。输出路径需位于 build 下，且本次运行前不存在。

    python tools/replay_record_caller.py --apk <P06 第二轮留档 APK> --sha256 2743bf6a5dd3219beb3d756a79cb8f97c30f8cd18ed64dde791b7c1d68744180 --out build/replay-record-caller

该轮预期输出 forged-success。脚本另可使用 --uri-after-share 验证采用内容提供器的候选，先完成应用内分享，再由独立应用发送已知记录 URI。该模式的 external-record-status 表示外部调用观察到了已有记录的判定结果。

使用上述脚本冷启动专用模拟器后复现 forged-success。目标与调用应用的安装 UID 分别为 10150 和 10151，目标安装 APK 哈希与本轮候选一致。[重放回执](0.6.20-record-caller-replay.json)
