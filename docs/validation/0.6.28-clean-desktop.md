# v0.6.28 干净 Windows 交互复核

专用 VMware 虚拟机从空白虚拟磁盘安装 Windows Server 2022 Standard，内部版本 20348.1006。两次双虚拟 CPU 启动在系统进入首个用户会话前记录相同的停止码。保留系统磁盘，仅将该测试虚拟机的配置改为一个虚拟 CPU，系统完成首次登录。此过程记录的是该虚拟机的恢复结果。

来宾基线没有 Java、ADB、模拟器或 Python，无 Android SDK、应用相关环境覆盖和活动网卡。Windows PowerShell 5.1 核验同版 ZIP 后，EXE 对 P03 和 P05 完成输入身份校验，覆盖的计划分别为 4 步和 8 步。两份候选哈希与 r2 评审包一致。

从同一 EXE 构建的隔离安装器通过安装、自检和卸载。已安装程序与交付 EXE 哈希一致，卸载移除了隔离注册信息并保留了测试导出文件。随后在登录会话启动便携版，观察到 Lazarus Agent 原生窗口、两个 WebView2 渲染进程和 HTTP 200 响应，WebView2 安装包的发布者签名校验通过。

该来宾用于离线 Windows 交互复核，未运行 Android 模拟器。首次下载和复用在另一专用来宾验证，Android 16 样本行为在宿主机的专用模拟器验证。各路径使用同一份便携 EXE，本次实际模型调用为零。
