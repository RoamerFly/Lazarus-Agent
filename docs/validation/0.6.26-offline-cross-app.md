# v0.6.26 跨应用离线复测

使用冻结的自有 APK 和随包分发的编辑轨迹，在 v0.6.26 对应源码上重新编辑、回编、签名并复测。Android 16 x86_64 专用模拟器回读已安装候选的哈希，然后检查固定操作。四个正例共通过 38 步，另有一份安装和启动成功但功能失败的反例。

| 样本 | 复测内容 | 结果 |
| --- | --- | --- |
| P01 巡检单 | 恢复安装，南北两条路线分别跨冷启动保留 | 10 步通过 |
| P03 计时器 | 中文按钮和状态文本，连续两次计数递增 | 4 步通过 |
| P04 温度卡 | 单位切换、换算结果和冷启动保留单位 | 16 步通过 |
| P05 记录阅读器 | 依次打开 B、A 记录并检查冷启动后的内容 | 8 步通过 |
| N03 计时器反例 | 对同一标题先断言存在，再断言不存在 | 第一步通过，第二步拒绝，候选未获功能验收 |

交付目录中的 `v0.6.26-离线跨应用复测包.zip` 包含原包、签名候选、编辑轨迹、设备报告和 PowerShell 复测入口。解压后通过文件哈希校验，并用同版便携 EXE 完成五份样本的输入校验。目标 Android 环境就绪后，可在解压目录用 EXE 重新运行设备验收。

这些应用及编辑操作此前已用于开发，复测消耗零次真实模型调用。新需求下的工具选择见 [文件交接专项](0.6.26-flash-private-handoff.md)。[Windows 首次准备回执](0.6.26-first-runtime-windows.md) 记录独立的联网验证。
