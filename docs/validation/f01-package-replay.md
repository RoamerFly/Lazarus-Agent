# 评审包解压后的实际复测

本次使用已生成工程复核包解压后的三份文件，通过正式 v0.6.8 桌面 EXE 执行独立复测，没有调用模型。文件来自包内 `可分发样本/P01-agent-3`，复测输出写入新的应用存储根目录。

基准 SHA-256 为 `08ed16b9f6a149bd8063bae99dd72aad200dafea7d3a0504af004187bde20deb`，候选为 `3cb6ce313e96d3bc997b4431cb891f293398f3f875dea8d8dce7336214a87261`。EXE 返回 0，报告为 behavior-verified。原包默认安装失败，候选安装和启动通过，南北线切换、说明文字及两次冷启动在独立 10 步检查中通过，设备回读 SHA-256 与包内候选相同。

该执行发生在开发机的独立进程和专用模拟器，验证包内文件及指南入口可以重新运行。它与全新 Windows runner 的测试分别记录，非开发者实际试用仍待提供。原始报告、进度和退出码在本机 `build/f01-review/package-device-replay`。

复核包还经 Python 校验器核对所有登记文件及 APK 验收报告，并在实际解压目录运行 PowerShell 文件校验。PowerShell 5.1 的正反例测试中，正确文件返回 0，追加字节后的文件返回 1。
