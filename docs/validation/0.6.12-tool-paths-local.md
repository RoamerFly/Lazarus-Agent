# v0.6.12 工具路径本机预检

为复查 v0.6.11 在英文 Windows 读取中文路径中的 `apksigner.jar` 时的失败，本机预检将构建工具、Apktool JAR、应用存储、输出及 TEMP 放在含中文和空格的路径。PATH 只保留 Windows 系统工具，运行时以绝对路径调用已配置的 Java。先按通用构建入口解包、回编、重签名并验签，再由工作台 API 导入原始巡检单，关闭模型运行安装门槛规则。[v0.6.11 正式包失败记录](0.6.11-independent-windows.md)

通用回编通过。规则运行中，原包按 Android 16 的默认安装策略因目标 SDK 22 被拒绝，规则改为 24。新 APK 成功安装启动，点击 `Open south route` 后出现 `Inspect the pump seal`。导出件与设备回读 SHA-256 均为 `cbbbaf40912fe2b9564961989d3aec143a92cc5ea2172c9088ba9885f7f3b64e`。原始记录位于本机 `build/f01-review/中文工具 全流程预检`，相关源码为 `90692e1`。

预检使用已有的专用模拟器和 Java。英文 Windows 干净机器的正式安装包复验单独记录。
