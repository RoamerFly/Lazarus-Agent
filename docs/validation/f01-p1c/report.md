## 实际修复证据与适用范围

- P01 第三轮三次构建。第一候选安装通过但启动后未观察到目标页面。第二候选冷启动后未恢复南线。第三候选预检和独立验收通过 10 步。静态复查记录其私有文件回退和遗留的错误接口尝试。
- P02 三轮均从原包复现，并依据目标系统证据添加可选 HTTP 兼容库。每轮只改清单、构建一次。原包无真实归档文件，本例核验原有操作的恢复。
- P04 通过候选由运行时真实输入驱动数值换算，通过私有首选项保存显示单位。差异复查绑定候选哈希，运行时的边界取已记录的步骤与设备。
- P06 实际出现两类修改。非导出内容提供器只读打开私有记录，另一候选用显式 Intent 限定为本包接收页面。接收端读取流并核对首字节。部分候选仅按字符串前缀限制规范化路径，外部 URI 安全性需另外验证。
- 样本使用合成数据。物理设备、额外 Android 版本和第三方应用分别使用对应验收记录。
