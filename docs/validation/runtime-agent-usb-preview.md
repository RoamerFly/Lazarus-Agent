# 运行中问题修复、低延迟预览与 USB 设备

验证日期：2026-11-24。

## 智能体输入与修复循环

带截图的消息原来只保存本地反馈，不进入模型工具循环。现统一进入通用 APK Agent，可同时接收用户需求、当前基准 APK、问题截图、最近反馈、应用 PID 日志及独立验收步骤。截图使用真实 `image_url` 内容块，不以 OCR 文本替代；继续修复可以复用上一张反馈图。没有启用模型时仍保存本地反馈。

当前 DeepSeek Flash 的图片输入格式依据[官方图像指南](https://api-docs.deepseek.com/guides/vision/)。对不处理图片的 DeepSeek 型号明确提示改用 Flash。图片另有上传上限，不将 base64 字符数当成文本上下文预算。

通用工具新增应用运行日志读取和按需公开错误查询。查询通过 Flash 独立的服务端搜索请求完成，再把结果交回代码编辑循环；每轮最多两次，不混用服务端搜索工具与本地函数工具，遵循[官方联网工具约束](https://api-docs.deepseek.com/guides/web_tools/)。查询不是预置软件专用脚本，网络资料作为待核查证据。模型仍可自主搜索与修改 APK 文件、构建、安装测试和操作隔离设备。能够启动不构成功能验收。

## 预览与 USB

在运行记录右侧选择模拟器或已授权 USB 手机。未授权、离线和断开均有对应提示。显示手机画面无需先修复 APK；自动修复验证继续使用专用隔离设备。真机试运行仅执行保留数据安装，不自动卸载、清空、降级或绕过 Android 安装限制。系统包禁止覆盖，手机实际 API 必须与所选运行目标一致。

模拟器优先读取原始 screencap 帧并在主机转换为 JPEG，不支持的像素布局回退 PNG。USB 设备切换时即启动手机内置 screenrecord 的无音频 H.264 输出，由 EXE 内置 PyAV 解码，只保留最新预览帧；静止画面会主动释放完整帧，避免等待流探测超时。不安装辅助 APK、不保存视频文件。视频不可用时使用压缩 PNG 截图，避免逐帧传输原始全分辨率像素。传输在切换、断线或闲置后结束；录屏命令到期后可重建。方向变化时刷新坐标，拒绝旧方向的点击。

画面限制长边约 1280。前端顺序调度，截图模式目标间隔约 350 ms，视频模式约 90 ms；输入完成立即刷新，显示实际画面往返耗时。点击和滑动按 object-fit 留白及设备原始分辨率换算，设备切换后拒绝旧画面输入。实际帧率与端到端延迟取决于设备、编码、ADB 与 USB 链路。
