# v0.6.30 工作台功能验收范围

同版便携 EXE 来自 `b251490`，通过 PyInstaller 自检。实际运行打包后的工作台，在本机以留档工具操作完成两次回编和签名，再在 Android 16 API 36 x86_64 专用模拟器独立安装、回读候选哈希并执行用户步骤。真实模型调用为零。

| 用例 | 安装和启动 | 功能结果 | 下载入口 |
| --- | --- | --- | --- |
| 巡检单 | 通过，回读与下载 APK 同哈希 | 十步全部通过 | 功能验收下载 HTTP 200 |
| 巡检单矛盾断言 | 通过，回读与下载 APK 同哈希 | 前十步通过，第十一步按预期失败 | 功能验收下载 HTTP 409，候选下载可用 |

在 960×640 和 1440×900 两种窗口尺寸，以 Edge 渲染实际 EXE 服务的页面，确认两种状态的下载文案、外部应用调用未测提示、布局和下载字节。测试期间在隔离任务内替换候选文件，两个下载入口均返回 HTTP 409，随后还原。旧验收报告可从工作台下载带明确覆盖字段的副本。

同一 EXE 的独立复测入口另外对正例 APK 执行两条互相矛盾的断言。候选安装启动通过，第一步通过，第二步失败，进程退出码为 1。专项复测包绑定同版 EXE、源码 ZIP 和两份设备报告。完整 42 轮及既有 Windows 准备和展示材料见 [v0.6.29 同版评审](0.6.29-review-final.md)。[本轮回执](0.6.30-workbench-coverage.json)

两次构建复测包字节一致。宿主 Windows PowerShell 5.1 解包后核对了 14 个登记文件，使用同版 EXE 核对两份样本输入，并从解包目录在 Android 16 再次通过巡检单十步。隔离 Windows 来宾的 VMware Tools 在等待期限内未就绪，任务在传入材料前终止。新版冻结预检重算了 42 轮，除构建身份外与 r3 逐项一致。

后续独立复核已恢复来宾交互登录，完成同一专项 ZIP 和 EXE 的自检、输入校验及原生页面渲染。结果和此前未就绪的尝试分别留档。[新版隔离 Windows](0.6.30-isolated-desktop.md)
