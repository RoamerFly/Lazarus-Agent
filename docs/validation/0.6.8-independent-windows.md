## 从首次安装到独立行为验收

[Fresh Windows runtime 42023115517](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42023115517) 在全新 Windows runner 使用正式发布安装器。限定 PATH 后启动实际桌面程序，经工作台 API 确认五类目标组件缺失，再通过同一入口准备 SDK、模拟器、API 36 镜像、构建工具和 Java。首次准备耗时约 66.12 秒。再次准备返回已有环境可用。

WHPX 检查返回 installed and usable。复测前，对已安装 EXE、受控 Java、ADB 和 emulator.exe 分别配置 Internet 出站阻断，保留本机通信。随后通过已安装 EXE 的 `--replay-acceptance` 入口执行包内固定步骤，退出码为 0。该阻断范围是所列可执行文件，未宣称断开整个 runner 的网络。

10 步包括初始北线、切换南线、检查原南线说明、冷启动保留南线，再切北线并冷启动检查原北线说明。复测完成后的运行目录约 6,852,856,599 字节，约 6.38 GiB，包含已准备组件与新生成的模拟器数据。它与首次准备尚未运行时的占用分别计量。
