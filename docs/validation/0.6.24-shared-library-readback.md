# v0.6.24 离线规则共享库声明回读

v0.6.22 固定回归中，P02 离线规则生成的归档阅读器通过了 Android 16 固定步骤。随后在 Windows 用 SDK 的 AAPT 回读该候选时，`dump xmltree` 退出 `0xC0000005`，`dump badging` 显示库名为空。

在同一原 APK 上检查到新增字符串属性只设置了类型化值索引。将原始值索引和类型化值索引均指向库名后，回读恢复。继续沿正式离线规则入口重做对齐和签名，AAPT 从签名后的 APK 读出 `org.apache.http.legacy`。工作台的清单差异也记录了新增共享库。相关字段定义见 AOSP。[二进制 XML 属性结构](https://android.googlesource.com/platform/frameworks/base/+/master/libs/androidfw/include/androidfw/ResourceTypes.h) · [签名候选回读回执](0.6.24-shared-library-readback.json)

源码单元检查共 219 项，215 项通过、4 项跳过。本次候选的安装和行为验收另用固定 P02 步骤重放。
