# v0.6.28 同一便携 EXE 的空目录准备

在专用 Windows Server 2022 测试机指定一个此前不存在的存储目录。测试前五项组件均缺失。七种无效同意输入都返回 HTTP 400，准备任务与保存状态保持初始状态。显式授权后，进度接口报告五项组件全部下载并通过发布方哈希校验，累计约 1.42 GB。

程序用时 827.3 秒报告 Android 16 环境就绪。再次准备返回就绪，未发起新的下载任务。独立探针核对同一目录，再次确认五项可用和直接复用，并执行了 ADB 与 Temurin Java 版本查询。

同一测试机另使用候选 EXE 和对应的 NSIS 脚本完成隔离安装、自检和卸载。安装后的 EXE 哈希与便携版一致。卸载移除测试安装及登记，保留导出文件。

本机隔离运行检测到原生工作台窗口、WebView2 渲染进程和 HTTP 200。截图工具未能激活窗口。测试虚拟机无已登录的图形会话，模拟器加速检查返回退出码 3。虚拟机的交互桌面启动与设备行为仍待复核。
