# 复核包反例设备版本核对

校验器和反例复测脚本现在核对三个字段。复测目标 API、结果行的 API 和候选设备记录的 API 必须一致。已有 APK 哈希、安装启动和矛盾断言检查继续使用。

重新校验 v0.6.18 原始评审 ZIP，1698 个文件、89 个可分发样本及 1 个反例通过。另复制原包，将反例结果行从 API 36 改成 API 35，并重算包内文件哈希。旧校验器通过该变体，新校验器按设备版本不一致拒绝。

使用固定输出程序执行新版 Windows PowerShell 反例脚本。目标、结果行与设备记录均为 API 36 时脚本退出 0。仅结果行或仅设备记录改为 API 35 时，脚本均以设备版本不一致退出 1。这次验证覆盖脚本的报告核对逻辑，设备行为仍按实际复测记录判定。[机器回执](review-counterexample-api.json)
