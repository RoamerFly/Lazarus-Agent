# Agent 的外部调用证据范围

工作台的清单检查保留 AAPT 原始声明，同时提供明确的导出和启用值。缺省或资源引用在规范化结果中保留未知。应用内预检单独标记外部调用未观测。模型得到的说明区分 URI、MIME 和额外参数的路由匹配，与需要单独核对的调用来源及权限。

使用连续编辑专项的两份实际 APK 调用工具。结果显示两份均保留导出的接收页。第二份新增的 Provider 明确未导出。清单结论只覆盖组件声明，外部 UID 的实际调用由独立探针验证。[回读回执](agent-caller-evidence-scope.json)

此变更建立在连续编辑修复源码之上。v0.6.24 的本地 EXE、冻结回归和评审包按各自构建记录复核。
