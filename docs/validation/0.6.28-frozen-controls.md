# v0.6.28 冻结用例的离线对照

使用 v0.6.28 构建对应源码 `cbd58ed`，在 Android 16 API 36 x86_64 专用模拟器重跑 P1C 固定六个正例的无语义改动回编和本地规则对照，各一轮，共 12 轮。原包、操作顺序和断言沿用冻结协议。所有轮次有终态，真实模型调用为零。

| 工作流 | 计划 | 成功构建 | 安装并启动 | 功能通过 | 无适用规则 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无语义改动回编 | 6 | 6 | 4 | 0 | 0 |
| 本地规则 | 6 | 3 | 3 | 2 | 3 |

| 用例 | 无语义改动回编 | 本地规则 |
| --- | --- | --- |
| P01 巡检单 | 安装失败 | 恢复安装与启动，冷启动后路线断言失败 |
| P02 归档阅读器 | 启动通过，读取断言失败 | 通过 6 步 |
| P03 泡茶计时器 | 启动通过，行为断言失败 | 无适用规则 |
| P04 温度卡 | 启动通过，行为断言失败 | 无适用规则 |
| P05 文件阅读器 | 启动通过，行为断言失败 | 通过 8 步 |
| P06 文件交接 | 安装失败 | 无适用规则 |

复核逐项比对原包与候选的 SHA-256。每份安装成功的 APK 与设备回读哈希一致。复核记录包括冻结清单、六份原包、九份构建产物、九份设备验收及十二份逐轮结果。逐轮结果中工作区的绝对路径已去除。P04 已在历史复验中观察，本次属于工程复跑。

准备好 Android 16 专用实验室后，在同版源码目录执行以下命令。选择一个新建的输出路径。

    python -X utf8 tools/run_f01_p1.py --protocol tools/f01-p1c-cases.json --out build/f01-offline-controls-review --controls-only

两列均按六个用例计分，其中三次规则不适用保留在分母。历史 P1C 的 Agent、一次构建、反例和留出门槛另见冻结复验报告。
