# v0.6.30 评审操作与答辩提纲

巡检单模拟维护班组更新平板。原 APK 的目标 SDK 为 22，Android 16 默认安装拒绝。对话要求恢复安装、保留原巡检内容，并在冷启动后恢复最后打开的路线。

| 时间 | 展示内容 |
| --- | --- |
| 0:00 至 0:30 | 对照旧 APK、目标 Android 16 和提交需求前固定的十步验收。 |
| 0:30 至 1:40 | 播放同版演示，查看自然语言需求、留档工具重放、回编签名与设备验收。 |
| 1:40 至 2:15 | 核对巡检单候选的下载与安装哈希。查看矛盾断言如何在安装、启动均通过后拒绝功能验收。 |
| 2:15 至 3:00 | 对照历史 Flash 批次和同版离线复跑，说明模型分析、外部 UID 测试及干净 Windows 首次准备分别属于哪份回执。 |

解压后把同版 `Lazarus-Agent.exe` 放在解包目录的上一级，或在命令中改用实际路径。

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\校验文件.ps1
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\复测样本.ps1 -LocalBuild -App "..\Lazarus-Agent.exe" -Sample 工作台演示 -CheckOnly
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\复测样本.ps1 -LocalBuild -App "..\Lazarus-Agent.exe" -Sample 矛盾断言 -Counterexample -CheckOnly

准备 Android 16 后去掉 `-CheckOnly`。预期巡检单十步通过，矛盾断言第一步通过、第二步失败。复测脚本会检查各自的结果。完整评测可从包内「冻结评测」复跑。

工作台的功能状态对应提交时指定的界面步骤。外部应用调用单列测试。历史 P06 曾出现通过正常操作却接纳外部记录的候选。另行交付的私有交接专项 APK 有独立 UID 测试回执。
