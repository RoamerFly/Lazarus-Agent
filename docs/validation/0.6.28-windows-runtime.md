# v0.6.28 Windows Android 16 环境准备

在专用 Windows Server 2022 虚拟机使用同版便携 EXE，沿用先前已授权的准备目录和已安装组件。v0.6.28 通过 Windows 原生证书校验访问 Temurin 发布文件，完成下载和安装。平台工具、模拟器、构建工具、Android 16 x86_64 系统镜像及 Java 五项均就绪。重新准备时直接复用已有组件。

独立探针调用该候选源码的运行环境检查和准备入口，并执行 ADB 和 Java 的版本查询。v0.6.28 便携 EXE 的命令行复测入口还在虚拟机中通过五份既有样本的输入校验。虚拟机的模拟器加速检查返回退出码 3，Android 设备行为验收见 [v0.6.26 跨应用复测](0.6.26-offline-cross-app.md)。

这次首次准备在同一隔离目录内分阶段完成。v0.6.26 验证首次同意并准备两项组件，v0.6.27 下载构建工具和系统镜像，v0.6.28 补齐 Java。非交互启动曾出现桌面渲染初始化错误，仍需以 v0.6.28 从空目录单独复跑并核对交互桌面启动。
