当前批次达到内部设备及语义联合门槛。签名发布、干净 Windows 和非开发者试用使用各自记录。

- `P02-rules-1`。平台共享库规则保留原读取代码，设备六步通过。生成的二进制库名缺少原始字符串索引，AAPT 回读失败。 v0.6.22 候选保留设备通过和构建工具回读失败两项记录。此候选排除出可分发样本。
- `P06-agent-1`。新增限制固定 URI 的私有只读 Provider，显式发送到原接收页。接收页仍导出，可在本应用上下文读取固定 URI，缺少对外部调用来源的限制。 Android 16 x86_64 的应用内五步通过。外部 URI 对照在写入前显示无法读取，写入后显示 Shared。
- `P06-agent-2`。新增限制固定记录和规范化路径的私有只读 Provider。原导出接收页及读取分支保留，缺少对外部调用来源的限制。 Android 16 x86_64 的应用内五步通过。外部 URI 对照在写入前显示无法读取，写入后显示 Shared。
- `P06-agent-3`。新增私有只读 Provider。原接收页仍导出，对外部 Intent 只按固定 /record URI 判断后在自身上下文读取。 Android 16 x86_64 应用内五步通过。按该轮实际 URI 对照，写入前显示无法读取，写入后显示 Shared。
