# v0.6.17 签名候选 · 替换输入验证

新增「替换输入」设备动作和多步验收语法。点选普通文本框后，使用 `替换输入 | 新值`。工作台检查焦点、应用包名、可编辑字段和资源 ID，输入完成后读取同一字段的实际值。动作只允许英文、数字、空格及 `_ . -`。现有「输入」继续向当前焦点输入文本。

| 验证路径 | 实际结果 |
|---|---|
| 源码执行器，Android 14、15、16 | 每个系统均把 Counter 的预填 `0` 替换为 `2147483646`。有溢出的候选随后在上限断言处失败，已修正候选每个系统均通过 12 步。 |
| 签名 EXE，DeepSeek Flash，Android 16 | 导入有溢出的候选，模型直接调用 `replace_input` 并读取到 `2147483646`，随后通过 12 步预检。工作台另行完成 12 步独立验收，并导出新候选。 |
| 同一签名 EXE，关闭模型，Android 16 | 复跑新候选 16 步通过，覆盖 `0 → 5 → 4`、十位数替换、达到上限后的重复点击和冷启动保持。安装回读、候选文件和下载件的 SHA-256 一致。 |
| 干净 Windows | 候选安装、自检、输入校验、篡改拒绝和卸载检查通过，卸载保留输出。另一台干净 Windows 首次准备运行环境用时约 101 秒，原有巡检单 10 步复测通过。 |

单元测试共 203 项，199 项通过、4 项跳过。新增检查覆盖密码框、外部应用焦点、焦点转移、截断输入，以及报告缺少字段回读证据的情况。前端解析同时核对「输入」与「替换输入」。

Windows 证据绑定 `a48ce0b` 的候选构建。本轮真实应用试验单独记录，正式参赛复核包对应已发布的 v0.6.16。[签名构建](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42109645786) · [安装检查](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42110501738) · [干净 Windows 复测](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42110500737) · [可解析回执](0.6.17-replace-input.json)
