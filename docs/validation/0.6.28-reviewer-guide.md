## 评审复跑

先按包内「从这里开始」核对哈希。准备好 Android 16 后，在已准备的 Windows 电脑上断开外网，保留本机进程通信，然后在解压目录执行以下命令。便携 EXE 如放在其他位置，可替换命令中的路径。

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\复测样本.ps1 -LocalBuild -App "..\Lazarus-Agent.exe" -Sample 工作台演示
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\复测样本.ps1 -LocalBuild -App "..\Lazarus-Agent.exe" -Sample N03 -Counterexample

演示候选应通过十步。N03 应在候选安装和启动通过后，于第二步拒绝功能验收。两个脚本输出的报告均写入解压目录下的「复测结果」。可先追加 `-CheckOnly` 检查程序和样本身份。

若评审想看一次新的模型改造，使用自己的模型配置，重新导入原 APK，再提交需求和固定步骤。本包中的 51 秒视频和四份样本来自离线重放。历史 P1C 的预注册方案、逐轮记录与对照报告位于源码 ZIP 中的 `docs/validation/f01-p1c` 和 `docs/science-superpowers/preregistrations`。
