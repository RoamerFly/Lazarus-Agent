# F01 评审包发布一致性复核

2026 年 11 月 6 日使用仓库内的更新公钥校验发布清单。校验器同时核对源码 ZIP 的 Git 提交和程序版本、发布回归及录屏回执对应的实现提交，以及视频和演示 APK 的哈希。源码归档提交可以包含后续材料整理，发布实现提交用于对应桌面版和录屏。

| 输入 | 结果 |
| --- | --- |
| v0.6.18 正式评审包 | 通过，发布清单签名有效 |
| v0.6.19 本地签名评审包 | 通过，发布清单签名有效 |
| v0.6.22 本地工程复测包 | 通过文件与留存证据校验，发布签名字段为空 |
| 换入另一版本的有效签名发布清单 | 拒绝，版本不一致 |
| 改写演示录制的实现提交 | 拒绝，录屏与发布构建不一致 |
| 换入另一版本的源码 ZIP | 拒绝，源码归档提交不一致 |
| 改写发布清单的分离签名 | 拒绝，签名校验失败 |
| 从签名交付包删除清单与签名 | 拒绝，缺少完整清单 |

五个反例均重新计算外层 SHA-256 清单，历史交付 ZIP 保持原样。本轮覆盖归档文件和留存证据，安装及设备复测采用各版本的独立记录。
