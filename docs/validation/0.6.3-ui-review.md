## 动画与可访问性

只使用短时 opacity/transform 入场和按压反馈。支持 prefers-reduced-motion，关闭动态时仍可完成所有操作。未加入持续发光、滚动驱动或大面积模糊动画。

页面与大弹窗隐藏滚动条。对话历史和弹窗内较长内容仍支持滚轮、触控板和键盘滚动。375/768px 浏览器页面保留纵向阅读，桌面 960px 起一屏展示。

验证了追加消息保留节点、阅读位置不跳动、位于底部时跟随新消息、改造需求转入弹窗、复现步骤关闭后重开仍保留、键盘焦点可见。浏览器未记录 JavaScript 异常。额外通过文件选择控件导入已签名示例 APK，核对完整页面渲染与诊断状态，并增加页面控件引用完整性的回归测试。
