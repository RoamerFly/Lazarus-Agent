# v0.6.24 Windows 独立复核入口

将本地工程评审 ZIP、其回执和固定的便携 EXE 放在同一目录。打开 Windows PowerShell 5.1，在该目录执行下列命令。脚本在解压前核对 ZIP 与 EXE 的哈希，在调用解压脚本前核对它和 SHA-256 清单的原始字节。

    $inputs = @{
        Archive = ".\v0.6.24-本地工程评审包.zip"
        Receipt = ".\本地工程评审包回执.json"
        App = ".\Lazarus-Agent.exe"
        EvidenceDirectory = ".\Windows 复核结果"
    }
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Windows独立复核.ps1 -Archive $inputs.Archive -Receipt $inputs.Receipt -App $inputs.App -EvidenceDirectory $inputs.EvidenceDirectory -Mode Inputs
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Windows独立复核.ps1 -Archive $inputs.Archive -Receipt $inputs.Receipt -App $inputs.App -EvidenceDirectory $inputs.EvidenceDirectory -Mode Prepare
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Windows独立复核.ps1 -Archive $inputs.Archive -Receipt $inputs.Receipt -App $inputs.App -EvidenceDirectory $inputs.EvidenceDirectory -Mode Device

- **Inputs** 将材料解压至新的结果目录，运行演示样本与矛盾断言反例的输入校验。
- **Prepare** 在独立存储中打开工作台。由复核人员选择准备 Android 16，按界面确认下载条款。等待 PowerShell 显示环境就绪后关闭工作台。保留准备前后清单和原始回执，已就绪的环境会单独记录。
- **Device** 沿用 Prepare 的存储，按包内脚本复跑十步演示和矛盾断言反例。只有同版 Prepare 回执有效时才运行。设备报告保存目标 API、ABI、安装回读和断言结果。

本机已验证 Inputs、Prepare 缺件及复用两种状态，并验证错版 EXE、改写的解压脚本和缺件状态下运行 Device 均被拒绝。复用测试使用已有 SDK 和 Java 组件。首次下载、干净 Windows 上的设备复测及非开发者独立试用仍分别待验证。[机器回执](0.6.24-windows-review-path.json)
