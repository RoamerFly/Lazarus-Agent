# v0.6.24 归档阅读器本地复测输入

专项 ZIP 为 17,952 字节，包含队伍自建原 APK、离线规则生成的签名候选、冻结六步计划、便携 EXE 构建回执、清单回读证据、脚本和说明。EXE 单独随本地候选提供，启动前核对其哈希。ZIP 和候选 APK 的文件哈希见机器回执。[本地复测包回执](0.6.24-local-archive-replay-bundle.json)

在含中文和空格的新目录中解压后，用 Windows PowerShell 5.1 和配套 EXE 运行输入校验。脚本逐文件核对清单，再由 EXE 读取两个 APK 和固定六步，生成 `inputs-verified`。替换为 v0.6.22 EXE、修改候选 APK 或修改计划文字均被拒绝，且未写出新的复测报告。

包内提供准备环境和设备复测入口。两者使用解压目录下的专用应用存储。当前回执覆盖材料身份与输入校验，Android 16 的六步设备记录另行归档。
