# v0.6.25 Windows 安装复核

本机 Windows 11 23H2（22635.5240）使用 v0.6.25 便携 EXE 和 NSIS 3.11 构建一次性测试安装器。安装目录、应用存储和临时目录均包含中文和空格。使用独立注册项，关闭测试安装的快捷方式。

安装、已安装程序自检与卸载均返回 0。安装后的 EXE 与便携版 SHA-256 一致。自检进程使用纯 Windows 系统 PATH，并移除 Android、Java 和模型相关环境变量。卸载移除了测试注册项及安装目录，模拟导出文件的 SHA-256 保持一致。

从候选源码目录使用 Windows PowerShell 5.1 复跑，参数换成实际路径。NSIS 便携 ZIP 的来源和校验值见上一版复核说明。[NSIS 下载与哈希](0.6.24-local-windows-install.md)

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\test_local_windows_install.ps1 -App "C:\Review\Lazarus-Agent.exe" -BuildReceipt "C:\Review\本地构建回执.json" -MakeNsis "C:\Review\nsis-3.11\makensis.exe" -EvidenceDirectory "C:\Review\安装 复核"
