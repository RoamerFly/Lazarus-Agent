# v0.6.29 评审操作与答辩提纲

同版设备材料使用自有巡检单展示改造和验收流程。原包面向旧 Android，目标系统默认安装会拒绝。对话同时要求恢复安装、保留原巡检内容，以及在冷启动后恢复最后打开的路线。

| 时间 | 展示内容 |
| --- | --- |
| 0:00 至 0:30 | 对照原 APK、Android 16 和事前固定的验收步骤。 |
| 0:30 至 1:30 | 播放 v0.6.29 的 57 秒演示。查看留档工具操作、预检后的前台读取和十步独立验收。 |

| 2:10 至 3:00 | 展示四个自有样本与Windows 来宾的安装、自检与卸载回执。说明设备步骤在宿主机执行，修订安装器在来宾通过默认卸载，空白系统首次准备对应 v0.6.28。 |

准备 Android 16 后，在解压目录执行下列复跑命令。便携 EXE 放在上一级，其他位置可更改路径。只做身份检查时追加 `-CheckOnly`。

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\校验文件.ps1
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\复测样本.ps1 -LocalBuild -App "..\Lazarus-Agent.exe" -Sample 工作台演示
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\复测样本.ps1 -LocalBuild -App "..\Lazarus-Agent.exe" -Sample N03 -Counterexample

本版演示及样本设备复测通过留档工具重放执行。历史模型评测与本版工程验证分开统计。需要发起新任务时可在自己的工作台中使用模型配置。
