# v0.6.24 Windows 安装与卸载本地复核

使用 v0.6.24 本地构建回执固定的 EXE，按仓库安装器脚本生成一次性 NSIS 测试安装器。测试使用独立的注册表键、应用数据目录和安装目录，关闭桌面及开始菜单快捷方式。安装、应用自检与卸载分别记录退出码。[本地构建回执](0.6.24-local-exe.json) · [机器回执](0.6.24-local-windows-install.json)

在现有 Windows 11 上实测。安装路径及应用存储、临时路径包含中文和空格。安装后的程序与便携 EXE 的 SHA-256 一致。启动已安装程序自检时，PATH 仅含 Windows 系统目录，模型、Java 和 Android SDK 的环境变量从该进程移除。默认卸载移除了测试安装及其注册项，保留了模拟导出文件且哈希一致。

## 本地复跑

在仓库根目录运行以下命令，将路径换成实际文件。将 NSIS 的官方便携 ZIP 解压到任意开发工具目录，编译器无需安装到系统。实测使用 NSIS 3.11，下载 ZIP 的 SHA-256 为 `c7d27f780ddb6cffb4730138cd1591e841f4b7edb155856901cdf5f214394fa1`。[NSIS 3.11 便携 ZIP](https://sourceforge.net/projects/nsis/files/NSIS%203/3.11/nsis-3.11.zip/download)

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\test_local_windows_install.ps1 -App "C:\Review\Lazarus-Agent.exe" -BuildReceipt "C:\Review\本地构建回执.json" -MakeNsis "C:\Review\nsis-3.11\makensis.exe" -EvidenceDirectory "C:\Review\全新复核 目录"

指定的新目录会保留测试安装器、编译日志、已安装程序自检和回执。当前证据覆盖现有 Windows 上的隔离安装。干净系统首次准备、设备操作与非开发者试用分别记录。

另用错误的 EXE 哈希启动脚本。脚本在创建测试目录和编译安装器前拒绝该回执。

另交付可脱离源码运行的 Windows 隔离安装复核 ZIP。新解压目录已用同版 EXE 和固定哈希的 NSIS 3.11 便携 ZIP 复跑，安装、自检、卸载均返回 0，导出保留。错版 EXE 与错误 NSIS ZIP 在创建复核目录前被拒绝。此次使用现有 Windows 23H2，构建号 22635.5240。[独立解压复测回执](0.6.24-install-review-bundle.json)
