# v0.6.22 本地开发回归复测包

同版便携 EXE 对应源码 `f24d5a583586785d388ae5133e4141f538456686`。复测包收录通过语义复核的 15 份 Agent 候选与一份矛盾断言反例，覆盖 5 个正例请求。每个样本都有原 APK、候选 APK 和设备验收记录。全部 42 轮计分和逐包语义审查也在包内。未纳入样本目录的候选仅保留审查记录。[全组回归](f01-release-regression/0.6.22/report.md)

打包时从冻结评测检出重新审计原始记录，核对归档结果、候选差异和 EXE 构建回执。包内脚本使用明确的本地复核模式，要求另行提供 SHA-256 匹配的 EXE。正式包入口仍按包内发布清单核验。[复测包回执](0.6.22-local-regression-bundle.json)

本机另用同版 EXE 重放取自 v0.6.18 评审包的两个固定样本。巡检单在 Android 16 x86_64 上通过 10 步。矛盾断言候选通过安装和启动，第一步通过、第二步失败，EXE 返回 1，结果保持 incomplete。两轮设备回读哈希均与各自候选一致。当前证据为已配置 Android 环境的本机复测。[EXE 设备重放回执](0.6.22-exe-device-replay.json)

在新解压目录使用 Windows PowerShell 5.1 核对 56 个登记文件，并逐项运行 15 个正例和 1 个反例的输入校验。16 项均读回固定步骤与 APK 哈希，错版 v0.6.24 EXE 在生成结果前被拒绝。另用新版脚本走原 v0.6.18 发布清单入口，输入校验通过。用相同归档重新打包，ZIP 的 SHA-256 一致。
