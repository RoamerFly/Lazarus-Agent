# v0.6.24 本地工程评审包

同版方案、74 秒工作台演示、源码、冻结计划、42 轮计分和差异审查合入一个 ZIP。包内提供 15 份回归候选、1 份演示候选与 1 份矛盾断言反例，原 APK 和独立验收报告与各候选一起保存。Windows 安装及归档阅读器环境复测各有独立工具。固定 EXE 单列，脚本用构建回执绑定其 SHA-256。

在含中文和空格的新目录解压后，Windows PowerShell 核对 72 个登记文件。同版 EXE 通过演示候选与矛盾断言反例的输入校验。设备结果引用本版已完成的实测，重新解压后的设备复测另行记录。

重算外层哈希后，校验器仍拒绝四种变体。分别替换为其他提交的源码 ZIP、改写演示候选哈希、替换片尾设备画面、改写 Windows 安装复核工具的 EXE 回执。源代码和录制的提交标识也分别回读。
