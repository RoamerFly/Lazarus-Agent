# v0.6.10 首次环境准备后的导入失败

[干净 Windows 验证 42049020476](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42049020476) 使用正式 v0.6.10 安装器，限制系统 PATH，应用存储和 TEMP 含中文和空格。五类组件准备完成，同一运行时可复用。随后的巡检单导入返回 HTTP 400 和 WinError 2，本地规则尚未执行。

检查导入路径发现签名读取直接按名称调用 `java`。在仅含系统工具的 PATH 下，已准备的 Java 不会通过该名称找到。v0.6.11 将签名读取改为优先使用已发现 Java 的绝对路径，保持现有证书验证参数和 PATH 回退。该入口供原包导入、候选验收和导出共用。修正后已在本机清除 PATH 中的 Java，并对同一原包执行真实签名验证。

前序补测曾在 Java 下载时收到 HTTP 504，也曾在平台工具下载时收到连接超时。这些请求没有进入导入阶段。工作流现在保留每次准备状态，对指定临时网关错误和连接超时最多尝试三次。[Java 网关错误运行](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42046163306) · [连接超时运行](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42047240221)
