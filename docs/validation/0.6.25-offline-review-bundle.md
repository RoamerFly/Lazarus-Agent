# v0.6.25 离线样本与 Windows 复核包

同版便携 EXE 在 Android 16（API 36，x86_64）模拟器对留档操作重建出的 APK 独立验收。对每个候选分别核对构建产物、设备安装哈希、启动与固定行为断言。本轮真实模型调用为 0。

| 用例 | 安装与启动 | 行为结果 |
| --- | --- | --- |
| P01 巡检路线 | 通过 | 10/10，南北路线可切换，冷启动后仍恢复上次路线与内容 |
| P03 计时器资源汉化 | 通过 | 4/4，点击中文按钮后分别确认两次计时提示 |
| P04 温度换算 | 通过 | 16/16，0 °C、212 °F、77 °F 三组结果及冷启动后的华氏单位均通过 |
| P05 阅读器记忆最近文件 | 通过 | 8/8，分别切换到记录 B 和 A，冷启动后恢复最近一项 |
| N03 矛盾断言 | 通过 | 先确认 `Field batch card` 可见，再要求同一文字不可见。第二步失败，功能验收保持未通过 |

交付目录中的 `v0.6.25-离线样本与Windows复核包.zip` 附原 APK、签名候选、独立报告、去除模型对话的操作轨迹和重放工具。四份通过样本与反例分目录保存。Windows 证据目录保留最初在干净系统中校验的原样本 ZIP，并绑定当时的回执与工作台截图。新包里的五份样本由现有 Windows 的同版 EXE 单独验证，干净 Windows 回执的样本范围为 P03 与 P05。

在含中文和空格的新目录解压后，用 Windows PowerShell 5.1 校验 37 个登记文件，并用同版 EXE 核对五份样本输入。随后按包内脚本重跑 N03，确认安装和启动成功、第二步行为断言失败。P01、P04、N03 从包内轨迹重跑后，文件差异均与原记录一致。重算 ZIP 内校验清单后，独立校验器仍拒绝替换桌面截图、改写 EXE 回执和伪造反例功能通过三种变体。

同目录交付 `F01-源代码-v0.6.25.zip`。ZIP 注释记录 EXE 的构建源码提交，程序版本号和全部条目已回读。源码包含自有评测夹具，已排除 CI 工作流和第三方旧 APK。准备 Android 16 后可按包内指南复测，反例使用 `-Counterexample`。编辑重放校验文件差异及新签名的 APK，自行重建的 APK 哈希可能和包内已验收候选不同。

本轮覆盖既有需求的离线回放及设备行为。42 轮全组回归仍以各自版本的记录为准。全新需求的实时模型规划、同版演示、干净 Windows 首次下载 Android 环境和独立试用分别留档。
