# 启动恢复任务时的历史状态

验证日期：2026-11-24。

工作台启动时会从 localStorage 恢复上次任务。原先直接按任务保存的结果渲染主界面，把历史安装失败当作刚发生的失败；历史成功也会错误暗示应用已在本次打开后运行。

新增仅存在于当前页面会话的显示状态，原始任务、测试、APK 与交付文件均保留。恢复已经结束的任务时，主界面显示中性的“本次尚未运行”，模拟器预览等待用户执行操作。运行记录中的真实成功或失败结果仍显示原有颜色，并标明“历史记录”。

本次请求执行被后端接受后立即切换为当前结果，即使执行很快、下次轮询只拿到结束状态，也会正常显示红色失败或绿色成功。恢复仍在执行的任务时继续展示进度和后续结果。USB 当前设备画面独立于历史 APK 的运行结果。

验证：Python 回归 204 项通过；Node 状态、会话与坐标测试 13 项通过。无头 Edge 使用真实页面与模拟 API，覆盖启动恢复失败、轮询后仍保持中性、历史错误留存、本次执行失败、页面重载及后台任务恢复。没有模型调用或 APK 修改。页面证据与检查回执保存在 `build/startup-history-ui/`。桌面 EXE 另以受控 self-test 验证。
