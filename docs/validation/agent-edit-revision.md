# 连续字面编辑的版本核对

v0.6.24 文件交接首轮的工具记录中，第 24、31、34 次调用尝试使用上一笔成功编辑返回的 SHA-256，旧实现仍要求重新读取同一文件。逐笔还原原 APK 的解包文件版本后，旧实现重现三次拒绝，新实现接受三次唯一匹配的字面替换。[前后对照回执](agent-edit-revision.json)

字面替换现在接受本轮读取或成功写入该文件时返回的最新 SHA-256。每次仍核对磁盘上的当前字节及旧文本的唯一匹配。按行替换继续要求重新读取，恢复文件会作废此前的编辑哈希。

本次证据覆盖工具行为和真实历史调用的离线重放。首轮未导出候选，固定回归按原结果留档。此变更独立于正在复测的 v0.6.24 EXE，待另行回编并重做设备验收。
