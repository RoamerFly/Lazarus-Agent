# v0.6.26 Windows 首次准备验证

在专用 Windows Server 2022 虚拟机启用 NAT 后，使用固定哈希的 v0.6.26 便携 EXE 和新的应用存储目录。初始缺少平台工具、模拟器、构建工具、Android 16 系统镜像和 Java。七种不合规的同意请求均返回 HTTP 400，三种不合规的本地记录也均未开启下载。

第一次授权请求在 HTTPS 证书验证处失败。Windows 的 HTTPS 请求和同工具链打包的 Python 探针随后均能访问官方仓库索引。工作台用新的隔离目录启动后成功下载并校验了平台工具和模拟器，全程保留证书校验。

构建工具连续两次卡在下载连接阶段。测试机访问 Google 的直接地址得到 HTTP 200，而旧路径的跳转服务器超时。v0.6.27 将官方直接地址设为首选，保留备用地址及发布方文件大小和哈希核验。

在同一测试机沿用已授权的准备目录，v0.6.27 保留平台工具和模拟器，成功下载并校验构建工具与 Android 16 系统镜像。重新读取同一准备任务后，缺项仅剩 Temurin Java，其发布文件链接遇到 HTTPS 证书验证错误。
