# v0.6.19 导出接收页面的外部调用复测

在专用 Android 16 x86_64 模拟器上安装发布回归 P06 第二轮的候选，核对 APK 与设备安装哈希。原界面操作写入合成 record.txt，接收页读取后显示 Shared。随后由独立 UID 的 ADB shell 显式启动该导出接收页，通过 EXTRA_RECORD_NAME 传入文件名。

| 检查 | 实际结果 |
| --- | --- |
| APK 与设备安装 SHA-256 | 2a40edd869d3d2246225fe191c7ea5f63cca0f6f3c00f898728456d69d4001e1 |
| 调用方和目标 UID | 2000 和 10150 |
| 外部传入 record.txt | 显示 Shared |
| 外部传入 missing-record.txt | 显示 Cannot read record |

设备结果证明导出入口接受外部传入的测试文件名，并区分已有合成记录和缺失记录。代码审查发现入口仅校验规范化父目录，未固定允许的文件名，原成功判定可暴露首字节是否为 42。当前设备复测覆盖上述两个文件名，调用方为 ADB shell。候选已排除出可分发样本。[机器回执](0.6.19-exported-receiver-probe.json) · [发布回归](f01-release-regression/0.6.19/report.md)
