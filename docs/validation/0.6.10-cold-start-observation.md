# v0.6.10 干净 Windows 冷启动观察失败

[补测 42044692602](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42044692602) 使用正式 v0.6.10 安装器，工作目录和 TEMP 均包含中文及空格。工作台完成首次环境准备，候选回读 SHA-256 与提交的文件一致。

原包因目标 API 22 被 Android 16 拒绝安装。候选安装成功，`am start -W` 返回 `Status: ok`，但窗口焦点未捕获。验收器做了四次界面观察，其中三次未发现目标应用节点，一次无法读取界面树文件。十步功能验收未开始，报告保持 `incomplete`，EXE 退出 1。模拟器本轮启动约 169 秒，日志中有 ColorBuffer 错误。先前通过的独立运行也出现过 ColorBuffer 错误，现有证据不足以确定因果。[完整复测报告](0.6.10-cold-start-observation.json)

0.6.10 的独立复测已另有通过记录，本轮补测说明该流程仍会遇到模拟器界面不可观察的情况。保留失败记录，后续分别运行候选复测和本地规则生成，避免一条验证未完成时丢失另一条的观测机会。[先前通过记录](0.6.10-independent-windows.md)
