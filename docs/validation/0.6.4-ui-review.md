# v0.6.4 弹窗、交互入口与模型预设审查

## 改动

- 修复记录使用 600px 宽的紧凑卡片与空状态。验证范围、步骤和提示采用中等尺寸，复杂改造与诊断使用大弹窗。内容增长时滚动区域保持在弹窗内。
- 移除“汉化设置”按钮、专用开关和主输入框的汉化示例。语言处理继续通过修复对话提出，候选下载链接使用统一名称。聊天请求通过通用参数读取当前模型配置，旧版请求参数仍可使用。
- 模型配置预设包括 DeepSeek、OpenAI、自定义兼容接口。预设只填入地址和模型，字段可继续编辑。切换提供方或手工修改地址时清空草稿密钥。测试密钥只对当前地址和模型有效，关闭窗口即清除。

## 核对的预设

| 预设 | 地址 | 初始模型 |
|---|---|---|
| DeepSeek | https://api.deepseek.com | deepseek-flash |
| OpenAI | https://api.openai.com/v1 | gpt-4.1-mini |
| 自定义 | 用户填写 | 用户填写 |

DeepSeek 值来自[官方快速开始](https://api-docs.deepseek.com/quick_start/agent_integrations/)。OpenAI 使用[Chat Completions 接口](https://developers.openai.com/api/reference/overview)及[GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini)。核对日期为 2026-11-04。

当前受限工具协议使用非思考模式，因此对官方 DeepSeek 请求增加 thinking disabled。此参数遵循[提供方的模式定义](https://api-docs.deepseek.com/guides/thinking_mode/)，不会添加到 OpenAI 或其他自定义服务请求。

## 验证

- 8 组窗口尺寸，80 次弹窗检查。弹窗没有横向溢出、遮挡或超过 2.6 的宽高比。
- 修复记录覆盖空列表与 40 条记录。桌面空状态的宽高比为 2.0。
- 通过真实文件选择入口导入已签名示例 APK，完整页面显示就绪。
- 使用本机接口桩验证预设填充、编辑自定义字段、保存后重开，以及测试过的草稿密钥不会跨提供方提交。未进行真实在线模型连通测试。
- 汉化通过普通对话发送，使用通用模型选择参数；界面没有语言任务专属入口。
- 追加对话保留旧节点与阅读位置，减少动态效果和键盘焦点检查通过。

169 项单元测试通过。
