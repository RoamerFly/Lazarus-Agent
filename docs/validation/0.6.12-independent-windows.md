# v0.6.12 干净 Windows 验证

正式安装器由 [发布任务 42052510695](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42052510695) 构建，源码为 `90692e1`。安装、自检、输入校验、篡改拒绝与卸载在另一台干净 Windows 上通过。[安装器检查](0.6.12-installer-check.md)

[候选复测 42053349250](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42053349250) 使用含中文及空格的应用存储与 TEMP。首次准备耗时 51.40 秒，复用检查通过。原 APK 被 Android 16 的默认安装策略拒绝，候选通过专用 x86_64 模拟器的 10 步独立验收，设备回读哈希与文件一致，正式 EXE 退出 0。[复测证据](0.6.12-windows-proof.json)

[从原包生成候选的补测 42053339294](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42053339294) 在环境准备后导入 APK，Java 启动器返回 `could not find java.dll`。该轮没有进入安装门槛修复。[独立小实验 42054125021](https://github.com/RoamerFly/Lazarus-Agent/actions/runs/42054125021) 使用同一发布方的 Temurin，在系统工具 PATH 下直接从中文目录启动复现退出 2。通过 ASCII 目录映射后 `java -version` 和 keytool 均退出 0，keytool 在中文工作目录按相对名称生成文件。该实验证明了映射方法的可行性。工作台集成后的整条生成路径仍需用正式安装包复验。
