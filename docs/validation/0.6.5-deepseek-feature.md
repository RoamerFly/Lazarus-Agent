# DeepSeek Flash 对话功能修改实测

核对日期为 2026-11-05。样本为 old_apk 中的 OI Notepad 1.3，输入 SHA-256 为 `3c5f3ebcbbae199a403304e195b63f29198729467d7900f85c28a18be9695539`。

在真实 Edge 渲染的工作台中选择 Android 16，上传原始 APK，在修复对话发送以下需求。

> 请把笔记编辑页面改为固定横屏，新建和打开已有笔记时都生效。笔记列表保持跟随系统。

使用 DeepSeek 官方接口和 `deepseek-flash`，非思考模式。凭据从用户指定的本地文件仅加载进测试进程环境。记录和提交均不含密钥。

模型实际调用了 `inspect_apk_activities`，读取当前 APK 声明的页面、方向、标签资源引用和 Intent 动作。第二轮调用 `set_activity_orientation`，选中 `org.openintents.notepad.NoteEditor` 并指定 `landscape`。本地构建器只接受检查结果中的 Activity 与白名单方向。

工作台调用已有 Apktool 解码、回编、对齐和签名流程，自动将目标 SDK 从 15 调整至安装门槛 24。由对话下载链接取得 APK，核对下载内容和候选报告哈希一致。网页无脚本异常。

候选文件为 `artifacts/verified/OI-Notepad-1.3-横屏编辑-Android16.apk`，466062 字节，SHA-256 为 `86a11ed3274273c425c5c3bfb9cbbbbc0826c0a21006a1476f5a49d2fbec3f17`。API 36 签名校验通过，签名证书 SHA-256 为 `45e56ef8382e61d9406f0256b7958b3e10138686b7f77a69d07489cb2632dbe0`。

使用新建的专用模拟器 ReviverFlash36A，API 36，720×1280，密度 240。仅操作测试模拟器。原版普通安装返回 INSTALL_FAILED_DEPRECATED_SDK_VERSION，原版界面对照使用安装门槛绕过选项。候选版通过普通安装，设备回读安装包哈希与下载文件一致。

模拟器的方向锁可能随退出固定横屏页面保留为横屏。验收通过显式改变系统方向验证列表跟随行为，保留了每一步 XML 和截图。

实测记录位于忽略目录 `build/deepseek-feature-lab/`，含 `live-result.json`、`android16-result.json` 和截图。截图的对照由测试操作生成。当前成果支持通过模型选择页面并改造方向，其他需求仍受已有工具能力约束。候选生成阶段在对话标注待设备复测，本次行为验收由独立的测试流程完成。

本轮 170 项单元测试通过，包含模型选择未观察到的页面时拒绝构建的回归。PyInstaller 桌面包自检通过，并从实际 EXE 的服务入口重复了真实模型检查、构建和候选下载。候选下载按钮与正文的可见间距核对为 10px。DeepSeek 工具调用协议参考[官方说明](https://api-docs.deepseek.com/guides/tool_calls/)。
