# v0.6.24 归档阅读器复测的环境回执

专项复测输入 r3 包含原 APK、签名候选和 Android 16 六步计划，配合同版 EXE 使用。Prepare 模式从当前工作台的本机接口观察运行环境。看到就绪提示后可关闭工作台。脚本将前后状态、缺少的组件和工作台退出码保存到 `prepare.json`。设备复测沿用单独的 Device 入口，失败时显示原退出码和报告中的失败原因。

| Windows PowerShell 5.1 复核 | 结果 |
| --- | --- |
| 在含中文和空格的新目录解压 r3 并执行 CheckOnly | 退出 0，输入身份通过 |
| 应用数据目录无运行时，打开后直接关闭 | 工作台退出 0，脚本退出 2，回执列出五项缺失组件 |
| 从本机已有组件建立测试目录后打开工作台 | 脚本退出 0，回执标记运行前即已就绪 |
| 设备被其他复测占用 | 同版 EXE 返回 1，报告记录安装、启动与功能均未运行 |
| 用受控回执重放设备未运行的分支 | r3 保留退出码 1，并把报告原因显示到终端 |

两份环境回执中的中文路径已逐项核对。本轮在现有 Windows 上执行。安装组件和模拟器设备重放分别留档，v0.6.24 在干净 Windows 上的首次准备仍待复核。[机器回执](0.6.24-archive-replay-prepare.json) · [同版六步设备回执](0.6.24-archive-reader-device-replay.json)
