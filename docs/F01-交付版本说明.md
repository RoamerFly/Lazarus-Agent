## 正式评审

在 v0.6.18 目录按提交准备说明选取方案、源码与演示。解压工程复核包，按包内说明核对 SHA-256 和发布清单，再用该版本复测巡检单、温度卡和矛盾断言反例。该包已有干净 Windows 验证记录，非开发者独立试用及负责人平台核对分别留档。[提交准备](F01-作品提交准备.md) · [正式包干净 Windows 复核](validation/0.6.18-fresh-windows-review.md)
