# 交付版本说明

赛事主交付材料使用 v0.6.18。该版完成 42 轮开发回归，正例设备断言通过 17/18，候选语义复核通过 15/18，主案例及温度卡各 3/3，六轮反例均明确拒绝，错误验收为零。正式评审包中分发的同包文件交接候选来自已审查的专项轮次。

## 文件定位

主交付目录为项目根目录下「交付/v0.6.18」。其中包括方案 PDF、65 秒实际演示、源代码 ZIP、工程复核 ZIP 和校验回执。每项上传文件对应关系见提交准备说明。[提交准备](F01-作品提交准备.md) · [正式包干净 Windows 复核](validation/0.6.18-fresh-windows-review.md)

工程候选目录为「交付/v0.6.19-本地复核」。其中包括本地安装器、便携包、六页方案、65 秒实际演示、源码 ZIP 和 3.25 MB 的候选验证附录。目录中「本地版本使用说明.md」给出本地安装器校验及三个样本的复测命令。复测回执单独位于附录旁，文件哈希绑定最终 ZIP。[候选本机复测](validation/0.6.19-local-supplement-replay.md)
