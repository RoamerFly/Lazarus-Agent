# 交付版本说明

赛事主交付材料使用 v0.6.18。该版完成 42 轮开发回归，正例设备断言通过 17/18，候选语义复核通过 15/18，主案例及温度卡各 3/3，六轮反例均明确拒绝，错误验收为零。正式评审包中分发的同包文件交接候选来自已审查的专项轮次。

## 文件定位

主交付目录为项目根目录下「交付/v0.6.18」。其中包括方案 PDF、65 秒实际演示、源代码 ZIP、工程复核 ZIP 和校验回执。每项上传文件对应关系见提交准备说明。[提交准备](F01-作品提交准备.md) · [正式包干净 Windows 复核](validation/0.6.18-fresh-windows-review.md)

工程候选目录为「交付/v0.6.19-本地复核」。其中包括本地安装器、便携包、六页方案、65 秒实际演示、源码 ZIP 和 3.25 MB 的候选验证附录。目录中「本地版本使用说明.md」给出本地安装器校验及三个样本的复测命令。复测回执单独位于附录旁，文件哈希绑定最终 ZIP。[候选本机复测](validation/0.6.19-local-supplement-replay.md)

## 当前差距与下一阶段

v0.6.19 的 42 轮回归设备断言通过 15/18，候选语义复核通过 14/18，低于 15/18 的内部门槛。暂停和进程中断轮次保留在分母。文件交接第二轮的导出接收页面接受外部文件名，已通过独立 UID 的 ADB shell 验证其区分合成记录与缺失记录。该候选排除出附录的可分发样本。[回归与语义审查](validation/f01-release-regression/0.6.19/report.md) · [接收页面外部调用](validation/0.6.19-exported-receiver-probe.md)

当前开发分支已加入设备命令超时恢复。发生超时时，工具把失败反馈给模型并清除旧的设备观测，模型需要重新安装或核对后继续操作。新增回归检查验证超时后的重新观测流程，开发源码共 213 项单元检查，209 项通过、4 项跳过。这项修复晚于 c812e5b 签名候选及其材料，需由后续本地构建验证。

下一阶段先处理导出接收页面的输入边界，保持模型依据实际 APK 自主设计改动的通用流程，再以新的源码提交单独运行设备实测与量化回归。非开发者独立试用反馈和负责人平台核对仍需实际记录。
