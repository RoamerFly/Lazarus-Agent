## 兼容性结论

Android 15 默认阻止目标 API 低于 24 的应用全新安装。两个旧包的目标 API 均低于此门槛，这是基于清单和系统规则的判断。[Android 官方说明](https://developer.android.com/about/versions/15/behavior-changes-all#minimum-target-api-level)
